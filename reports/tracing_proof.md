# Tracing Proof

This project uses OpenTelemetry for tracing. The proof below was generated by running
the multi-agent workflow with console span export enabled.

## Command

```powershell
$env:OTEL_CONSOLE_EXPORTER="true"
python -m multi_agent_research_lab.cli multi-agent --query "Research GraphRAG state-of-the-art and write a 500-word summary"
```

## Provider

- Tracing provider: OpenTelemetry
- Service name: `multi-agent-research-system`
- Trace implementation: `src/multi_agent_research_lab/observability/tracing.py`
- Workflow implementation: `src/multi_agent_research_lab/graph/workflow.py`

## Observed Spans

The terminal printed OpenTelemetry JSON spans for the following workflow steps:

| Span Name | Agent | Example Trace ID | Evidence |
|---|---|---|---|
| `agent.supervisor` | supervisor | `0xc6a3b3a21a5a2bbf9c7c252e8e65de6e` | supervisor routing step recorded |
| `agent.researcher` | researcher | `0xf7790dc0c1f346cd084b55529b876160` | source collection step recorded |
| `agent.analyst` | analyst | `0x6d3659bfcbdb7ffb94ce66a4a072737d` | analysis step recorded |
| `agent.writer` | writer | `0xa2d8c4284ee6457abc6dbdb438c39dac` | final answer writing step recorded |

Each span contained OpenTelemetry metadata similar to:

```json
{
  "kind": "SpanKind.INTERNAL",
  "attributes": {
    "agent": "writer",
    "duration_seconds": 3.2748279000006733
  },
  "resource": {
    "attributes": {
      "telemetry.sdk.language": "python",
      "telemetry.sdk.name": "opentelemetry",
      "service.name": "multi-agent-research-system"
    }
  }
}
```

## Route Evidence

The CLI also printed the workflow route:

```text
Routes: supervisor, researcher, supervisor, analyst, supervisor, writer, supervisor
Trace events: 8
```

This proves that the workflow executed through the expected multi-agent path:

```text
Supervisor -> Researcher -> Supervisor -> Analyst -> Supervisor -> Writer -> Supervisor
```

## How to Reproduce

Run:

```powershell
$env:OTEL_CONSOLE_EXPORTER="true"
python -m multi_agent_research_lab.cli multi-agent --query "Research GraphRAG state-of-the-art and write a 500-word summary"
```

To turn terminal tracing off:

```powershell
$env:OTEL_CONSOLE_EXPORTER="false"
```
